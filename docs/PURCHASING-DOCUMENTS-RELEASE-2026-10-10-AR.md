# تنفيذ المشتريات والمستندات وأدلة الإطلاق

الإصدار المحلي للقالب والإضافة: **1.30.0**. مخطط قاعدة البيانات: **1.18.0**. هذا السجل يميز التنفيذ المحلي عن قبول الإنتاج؛ لا يعلن انتهاء جميع مراحل الإطلاق.

## أوامر الشراء

من مجموعة «المشتريات» افتح «أوامر الشراء». يمكن للموظف المخوّل إنشاء مسودة لمركبة محددة ومورد نشط، وإدخال سعر الشراء والتكاليف الإضافية بالريال ونسبة الضريبة. يعرض الطلب تفصيل المبالغ والإجمالي، ويتيح البحث وتصفية الحالة وترقيم الصفحات والتفاصيل ومرجع الاستلام وهوية المسؤولين.

تتطلب أول عملية تقديم اعتماد سياسة من مسؤول النظام: حد الاعتماد العادي، الحد الأعلى، إدراج الضريبة ضمن تكلفة الاقتناء أو استبعادها، وقاعدة إلغاء الطلب بعد اعتماده. لا توجد حدود مالية مفترضة في الموقع المحلي. السياسة تحفظ صاحب الاعتماد ووقته وسبب القرار وإصدارًا مستقلًا؛ كل طلب مقدم يحتفظ بالسياسة التي اعتمد وفقها حتى إذا تغيرت إعدادات الطلبات الجديدة.

الدورة: مسودة ← انتظار الاعتماد ← اعتماد أو رفض ← استلام تجاري. يمكن إلغاء الطلب قبل الاستلام بحسب الصلاحية والسياسة المحفوظة. يمنع اعتماد الموظف لطلبه، ويمنع تسجيل الاستلام بواسطة المنشئ أو المعتمد؛ يجب أن يسجله موظف مستقل. الطلب فوق الحد الأعلى لا يمكن تقديمه. الإلغاء بعد الاستلام غير مسموح بهذا المسار، لأنه يحتاج معالجة مخزونية ومالية منفصلة.

كل أمر يخص مركبة واحدة في حالة ordered أو in_transit أو received أو inspection. يمنع وجود طلب فعال آخر للمركبة نفسها. يسجل الاستلام التجاري المورد والتكلفة بدقة أجزاء الريال داخل معاملة واحدة مع الطلب والتدقيق، ويترك الاستلام المادي والفحص وحالة الإتاحة في خدمات المخزون القائمة. لا ينشئ هذا المسار مستند دفع للمورد أو تكاملًا خارجيًا.

الحفظ المتكرر والمتزامن يستخدم مفتاح طلب واحدًا، وتستخدم إجراءات الحالة رقم الإصدار لمنع معالجة شاشة قديمة. فشل التدقيق يرجع الطلب وتكلفة المركبة معًا. صلاحيات مستقلة للعرض والإنشاء والاعتماد والاعتماد العالي والاستلام والإلغاء، ونطاق الفرع يطبق على القراءة والتغيير. ترحيل الأدوار الافتراضية إضافي؛ التعريفات المدارة يدويًا والرفض الصريح للصلاحية يحتفظان بسلطتهما. يستطيع المسؤول ضبط أدوار المؤسسة من شاشة الصلاحيات القائمة.

## أرشفة عروض الأسعار

افتح نسخة العرض من «عروض الأسعار»، ثم شاشة الطباعة، ثم «إصدار وتنزيل المستند المؤرشف». لكل نسخة محفوظة رقم مثل `DOC-Q-123-V2-T1`، وإصدار قالب `quotation-1`، وتاريخ إصدار ومسؤول وبصمة SHA-256 لنسخة البيانات المالية. الإصدار المتكرر يعيد السجل والرقم نفسه. ينزل المستند HTML مستقلًا قابلًا للطباعة والحفظ PDF من المتصفح؛ قالب الأرشيف لا يحتاج ملفات تنسيق من الخادم.

الأرشيف يشير إلى نسخة العرض المحفوظة بدل نسخ هوية العميل إلى مخزن جديد. تعرض عمليات التنزيل البيانات الأصلية المحفوظة وتتحقق من بصمتها والصلاحية ونطاق الفرع ومن nonce مرتبط بالموظف. تدخل مراجع المستندات في تصدير الخصوصية؛ يمحو مسار الخصوصية الاسم الشخصي من النسخة دون إفساد البصمة المالية. تغيير مبالغ النسخة يظهر كفشل تحقق. البصمة تخص بيانات المصدر، وليست توقيعًا رقميًا أو بصمة ملف HTML بكل تفاصيله.

هذا التنفيذ يغطي عروض الأسعار. لا يدعي إصدار فواتير ضريبية أو عقود معتمدة أو حفظ ملفات PDF موقعة؛ أنواع هذه المستندات وترقيمها واحتفاظها ومتطلبات مزود الفوترة تحتاج سياسة محددة قبل تنفيذها.

## أدلة الإطلاق

من «إعدادات المنصة» افتح «أدلة الإطلاق». يسجل مسؤول مرجع تقرير فعلي دون بيانات اعتماد، وبصمته، وتاريخ انتهاء صلاحيته، وملخص نتائجه. يتطلب قبوله مسؤولًا آخر يراجع التقرير ويدون سبب القرار. تبقى المراجع القديمة محفوظة؛ تقبل بوابة الجاهزية فقط دليلًا معتمدًا للبيئة والإصدار الحاليين، لم تنته صلاحيته، ومراجعه مستقل عن مقدمه.

البنود المدعومة: اعتماد الخصوصية والشروط، اعتماد البيانات التجارية، اختيار مزودي الإطلاق وقبولهم، مراجعة الأسرار التاريخية، الجدولة والبريد، مراجعة الأمان، الأداء وإمكانية الوصول، النسخ الخارجي والاستعادة، واعتماد النشر. قبول دليل لا يتجاوز فشل HTTPS أو المخزون أو مطابقة الكتالوج، ولا يفعّل أي مزود تلقائيًا.

## النسخ والتحقق المحلي

قبل ترقية المخطط أنشئت نسخة محلية متسقة من **45 جدولًا و930 صفًا** خارج مجلد الموقع. تحققت استعادتها على MariaDB مؤقت منفصل عن قاعدة الموقع، وطابقت أعداد صفوف كل جدول، ثم حذفت قاعدة الاستعادة المؤقتة. بصمة النسخة:

`4663043baf9c2953d03aceb343377d60fec463fd4508fa769688549c3f87d5dc`

الأدوات:

```powershell
C:/xampp/php/php.exe tools/backup-local-workspace.php --create
C:/xampp/php/php.exe tools/verify-local-backup.php --verify BACKUP_FILE ISOLATED_PORT
C:/xampp/php/php.exe tools/release-preflight.php --inspect
powershell -NoProfile -ExecutionPolicy Bypass -File tools/build-release-package.ps1 -ReviewWorkingTree
```

أداة الاستعادة ترفض منافذ قاعدة الموقع المعتادة والخوادم التي تحتوي قواعد غير نظامية؛ قاعدة test فارغة أنشأها مثبت MariaDB يمكن أن تبقى دون تغيير. النسخة المحلية غير مصنفة نسخة مشفرة خارج الخادم، واختبار الاستعادة على الجهاز نفسه لا يحقق شرط الاستعادة على مضيف مستقل.

أصلحت أداة بناء الحزمة لتضمين ملفات الترجمة و404 وصفحة القانون ومحمّل الخطوط، وفحصت قائمة الملفات والبصمات. وضع `ReviewWorkingTree` ينتج حزمة مراجعة من المصادر الحالية، مع علامة واضحة في manifest؛ الوضع الاعتيادي يبقى مرتبطًا بالتزام Git نظيف. الحزمة لا تتضمن إعدادات قاعدة البيانات أو الاختبارات أو نسخ قواعد البيانات، ولا تعني اعتماد الإطلاق.

حزمة المراجعة النهائية: `.tmp/release-packages/auto-dealership-1.30.0-83bf3f66050d-review-b7ffd70e.zip`، وتضم **226 ملفًا**. بصمتها `61e1c86770fdd64c02e73e77bffd29a7fb4e3b084129124f09bcdbe6b47d196f`. ملف manifest المجاور يسجل بصمة كل ملف وعلامة `working_tree_review: true`. لم تُنشر الحزمة ولم يُنشأ التزام Git باسم المستخدم.

## التحقق والمتبقي

نجح الاختبار العام: **701 تحقق سابق + 52 تحقق للمشتريات والأرشيف وأدلة الإطلاق**، ونجح مسار المبيعات المستقل: **58 تحققًا**. تشمل الإضافة فصل المهام وحدود الفروع وتجميد السياسة ومفتاح الحفظ والتزامن ودقة الضريبة وفشل التدقيق والخصوصية ونماذج HTTP وnonce والتنزيل والعربية والإنجليزية. اجتاز PHP lint وفحص الترجمة والفروق.

الفحص المحلي يبقى **9 PASS / 3 FAIL / 9 MANUAL**. الإخفاقات: HTTPS للبيئة المقصودة، عدم وجود مخزون تشغيلي معتمد مؤهل، وبقاء الكتالوج compatibility. البنود البشرية لا تتغير دون دليل فعلي ومراجعة مستقلة.

لا تزال هناك معلومات وأعمال لازمة لإنهاء النطاق الكامل: بيانات بيئة النشر والنطاق والشهادة؛ المركبات والأسعار والصور المعتمدة؛ حدود سياسة الشراء وإلغائه واحتساب التكلفة؛ أنواع المستندات الرسمية وسياسات ترقيمها واحتفاظها؛ تحديد المزودين وعقود API وبيئة التجربة؛ أدلة الجدولة والبريد والأمان والأداء وإمكانية الوصول والنسخ الخارجي والاستعادة المستقلة والاعتماد القانوني والتشغيلي. لم تدخل بيانات تجارية تجريبية إلى قاعدة الموقع، ولم تنشأ اعتمادات إطلاق وهمية أو يتفعّل تكامل غير محدد.

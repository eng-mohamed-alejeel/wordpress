# إصلاح التسجيل واستعادة الوصول — 1.64.1

## السلوك النهائي

- التسجيل ببريد موجود يعرض أن الحساب مسجّل، مع تسجيل الدخول واستعادة كلمة المرور وطلب رابط تفعيل جديد. لا يغيّر كلمة المرور أو البيانات أو الدور، ولا يرسل رسالة تلقائية لهذا الحساب.
- ينطبق فحص التكرار على الحسابات المؤكدة والمعلّقة والقديمة، دون حساسية لحالة الأحرف. تشمل المعالجة مسار التحقق داخل المعاملة وحالة التعارض التي يعيدها WordPress.
- لا تظهر رسالة نجاح إذا تراجعت معاملة إنشاء الحساب بسبب حد إرسال رسائل التأكيد.
- مهلة إعادة الإرسال دقيقة لكل بريد وغرض؛ لا تنتقل بين حسابات مختلفة على شبكة واحدة. يبقى حد مستقل لحماية الشبكة من الإغراق، وتبقى حدود الإرسال لكل عنوان. لا يسمح تغيير حالة الأحرف أو حذف الكوكيز بتجاوز حد البريد.
- كوكي مهلة العرض يحتوي بصمة HMAC فقط، دون البريد، مع HttpOnly وSameSite وSecure عند HTTPS. حذف الكوكي يغيّر العرض فقط؛ الحماية الخادمية تحتسب البريد المقدّم.
- تصحيح البريد إلى العنوان نفسه يعامل كإعادة إرسال، ولا يسجّل تغييرًا وهميًا لعنوان الحساب.
- ملف المستخدم الإداري يميّز استخدام الرابط، وقبول SMTP، والانتظار، وإعادة المحاولة، والفشل، وانتهاء الصلاحية، والمعالجة المنتهية دون قبول إرسال مسجّل. لا تُعرض بيانات التأكيد السرية. اكتمال الوظيفة لا يعني وصول رسالة.
- أضيف فحص عنوان عام آمن إلى جاهزية المنصة، وتنبيه إداري وروابط إعداد العنوان، وإيضاح في صفحة التأكيد عند استخدام عنوان محلي أو HTTP.

## حدود البيئة التي تحتاج إعدادًا عند النشر

لا يستطيع تعديل الإضافة جعل `localhost` متاحًا من أجهزة العملاء. يجب ضبط عنوان WordPress وعنوان الموقع على النطاق العام الصحيح مع HTTPS، وضبط الوكيل العكسي إن وجد. لا يُستخدم عنوان منفصل لرسائل التأكيد لأنه قد يكسر كوكيز الأمان والنماذج والروابط اللاحقة.

الإرسال الأول يستخدم تنفيذ الحدث المحدد بعد حفظ المعاملة، دون انتظار WP-Cron. المحاولات اللاحقة تحتاج عاملًا دوريًا. شاشة مراقبة التشغيل الموجودة في `admin.php?page=adc-outbox` تعرض إعدادات العامل وآخر تشغيل والرسائل العالقة وأوامر الخادم. مثال عند توافر WP-CLI: `wp adc jobs run --path=/path/to/wordpress` كل دقيقة عبر جدولة الاستضافة. لا يثبت فتح الداشبورد وحده تشغيل الجدولة بصورة مستمرة.

قبول SMTP لا يثبت الوصول إلى صندوق الوارد. لا يوفّر موصل Gmail الحالي إثبات تسليم أو ارتداد لكل رسالة؛ لم تُضف حالة تسليم افتراضية أو مضللة.

## التحقق

تُنفّذ اختبارات التسجيل والتأكيد وإعادة الإرسال وكلمات المرور والصلاحيات على قاعدة بيانات مؤقتة مستقلة، مع منع البريد الحقيقي والشبكات الخارجية. تشمل اختبارات المتصفح ملفات ZIP المستخرجة، ورسالة الحساب الموجود وروابط الاستعادة، واستقلال مهلة الحسابات على الشبكة نفسها. بيانات الحسابات الفعلية وإعدادات SMTP وملفات المستخدمين لا تدخل الاختبارات.

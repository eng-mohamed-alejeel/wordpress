# البحث المدمج في الهيدر

نُفذ محليًا، ثم نُشر على الاستضافة ضمن الإصدار 1.54.2. تفاصيل النشر في `HOST-HEADER-RELEASE-1.54.2-AR.md`.

## السلوك

- أيقونة عدسة بمساحة 44×44 تفتح لوحة أسفل الهيدر دون تحريك المحتوى. لوحة محدودة العرض على الكمبيوتر وبعرض الهيدر على الجوال، بألوان الهوية الحالية في الوضعين. أصبح هيدر الجوال أكثر اختصارًا في صف واحد.
- استخدام عنصر `details` الأصلي يجعل الفتح والبحث يعملان عند تعطيل JavaScript أيضًا.
- عند توافر JavaScript ينتقل التركيز إلى الحقل؛ يغلق Escape اللوحة ويعيد التركيز إلى المشغّل. يمكن أيضًا إغلاقها بزر العدسة نفسه، أو الضغط خارجها، أو نقل التركيز إلى عنصر خارجها.
- اختُصرت اللوحة بطلب المستخدم إلى الحقل وزر البحث دون عنوان أو فقرة مساعدة أو زر إغلاق. نص الحقل: «ابحث عن سيارة بالاسم أو الماركة أو الموديل»، مع ترجمة إنجليزية وتسمية مستقلة لقارئ الشاشة.
- `Ctrl+K` و`⌘+K` يفتحان البحث دون اعتراض الاختصار داخل حقول التحرير. لا تُستخدم نافذة حوار مشروطة أو حبس للتركيز.
- إغلاق قائمة الجوال واللغة عند فتح البحث، وإغلاق البحث عند التفاعل معهما.
- زر مسح يظهر عند وجود نص. يبقى النص عند إغلاق اللوحة وإعادة فتحها في الصفحة نفسها. لا يُسجّل تاريخ بحث في المتصفح ولا تُرسل المسودة أثناء الكتابة.
- منع البحث الفارغ والمسافات فقط برسالة عربية أو إنجليزية. تعتمد النسخة دون JavaScript على التحقق الأصلي للمتصفح.
- يحتفظ البحث باللغة وبفلاتر الكتالوج المعروفة عند استخدامه من أرشيف السيارات؛ يبدأ من الصفحة الأولى. تُستبعد المعاملات غير المعروفة أو غير النصية، وتُهَرَّب جميع القيم.
- النتائج الفارغة تشرح العبارة المستخدمة وتتيح تعديل البحث، أو مسح الفلاتر مع الاحتفاظ بالعبارة، أو عرض جميع السيارات. البحث الأساسي نفسه لم يُستبدل بمحرك جديد.
- لا توجد اقتراحات حية أو طلبات شبكية قبل إرسال البحث؛ حركة فتح قصيرة فقط لمن لا يفعّل تقليل الحركة.

## التحقق

`wp-content/plugins/auto-dealership-core/tests/browser-header-search.cjs` نجح بـ **159 تحققًا** عبر العربية والإنجليزية، عرضَي 390 و1440، والوضعين الفاتح والداكن. يتضمن التنقل بلوحة المفاتيح، المسح، الإغلاق، غياب العناصر المحذوفة، حفظ العبارة، عدم تحريك الصفحة، عدم التمرير الأفقي، البحث الفعلي إلى النتائج الفارغة، استعادة العبارة، فحص axe للوحة، عدم وجود استثناءات JavaScript، البحث دون JavaScript، وحفظ الفلاتر.

فحوص إضافية ناجحة: إغلاق البحث وقائمة اللغة لبعضهما، إعادة التدفق عند 320px، اختصار `⌘+K`، والبحث عن اسم مأخوذ من سيارة منشورة وظهور نتائج فعلية. تمت مراجعة لقطة الجوال الداكنة بصريًا.

نجحت صياغة ملفات PHP/JavaScript المعدلة، وفحص تجميع CSS، وفحص نسخ الترجمة، و`git diff --check`. كل طلبات البحث للاختبار GET؛ لم تُرسل نماذج تواصل أو رسائل بريد ولم تُعدّل بيانات السيارات.

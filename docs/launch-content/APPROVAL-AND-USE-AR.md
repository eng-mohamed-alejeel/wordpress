# حزمة البيانات والمحتوى للإطلاق — المرحلة B

تحديث معلومات المالك: خُصصت الحزمة لشركة أوتو براندز بفروع جدة ومكة وحالة الإنشاء والخدمات والهاتف والبريد وسياسة العربون وثلاثة أيام. أُنشئت خمس مسودات داخل WordPress المحلي وجهز ملف أمثلة مخزون مستقل. البيانات الأساسية السابقة لم تعد كلها مجهولة؛ تبقى الحقول القانونية ومبلغ العربون وتفاصيل الاسترداد والضريبة والاستضافة مفتوحة. التفاصيل وحالة التطبيق في `AUTOBRANDS-EXECUTION-AR.md`؛ الفقرات التالية توثق إطار التحضير الأصلي.

بدأ إعداد المرحلة في 3 أكتوبر 2026. الحالة: محتوى تحريري جاهز للمراجعة، وبيانات المنشأة والسياسات والمخزون بانتظار المصدر والاعتماد. هذه الحزمة ليست شهادة اعتماد قانوني أو بيانات مخزون حقيقية.

## المحتوى الذي أصبح جاهزًا

`editorial.ar-en.json` يحتوي خمسة موضوعات بالعربية والإنجليزية: من نحن، التواصل، الأسئلة الشائعة، دليل اختيار السيارة، وحاسبة التمويل. لكل موضوع عنوان ووصف مختصر ومحتوى HTML، مع نصوص قصيرة للرئيسية والأزرار والحالة الفارغة والاشتراك الاختياري.

الصياغة مبنية على الوظائف الموجودة بالفعل. لا تتضمن أرقام مبيعات أو شهادات عملاء أو وعود ضمان أو تمويل أو مواعيد رد غير موثقة. عنوان AUTO BRANDS والارتباط بالمنشأة المذكوران في الشفرة الحالية مرجعان يحتاجان تأكيد المالك قبل إدراجهما في نص نهائي.

ملف `preview.html` يعرض النصوص محليًا بالعربية والإنجليزية. النماذج والحاسبة تظهر فيه كمواضع توضيحية ولا ترسل بيانات. يمكن فتح الملف في المتصفح للمراجعة التحريرية.

## بيانات يلزم استكمالها

املأ نسخة من `business-profile.template.json` خارج Git، وأرسل بيانات التواصل العامة المطلوبة فقط عبر القناة المناسبة. أبقِ أرقام الهوية والوثائق والبيانات الشخصية والمخزون ذي VIN في التخزين المقيد. الحقول الفارغة مقصودة، وليست قيمًا افتراضية للإنتاج.

| المجموعة | المصدر المطلوب | شرط القبول |
|---|---|---|
| المنشأة | الاسم القانوني والتجاري والتسجيل والعنوان ومالك المحتوى | تطابق المستند المعتمد والعربية والإنجليزية |
| الفروع | `../intake/branches.csv` | رمز فريد، عنوان واتصال وساعات عمل فعلية ومرجع اعتماد |
| المركبات | `../intake/vehicles.csv` و`vehicle-details.csv` | VIN ومواصفات وعدّاد وحالة وبيان سعر وصور وحقوق استخدام ومصدر مثبت |
| العروض | `../intake/offers.csv` | مركبات محددة وتواريخ وشروط وخصم موثق، بلا ادعاء تمويل غير معتمد |
| السياسات | مراجع الحجز والعربون والإلغاء والاسترداد والضمان والتسليم | تطابق العقود والوظائف المتاحة، واعتماد صاحب القرار |
| الخصوصية والشروط | المسودات الموجودة في `../legal/` | هوية ومسوغات ومتلقي بيانات ومدد احتفاظ وقنوات حقوق وتاريخ واعتماد قانوني |
| البيئة | عنوان staging HTTPS ومسؤول تشغيل | بيئة منفصلة عن التطوير واختبارات اتصال وبريد وجدولة ونسخ |

`vehicle-details.csv` ورقة إضافية تُربط بـstock_number وليست صيغة استيراد آلي. لا تفترض سعرًا أو عدادًا أو حالة عند غياب المصدر؛ العدّاد صفر قيمة فعلية عندما يؤكدها المصدر. تبقى بيانات التطوير الحالية محفوظة ولا يعاد توصيف معاملاتها كبيانات حقيقية.

## كيفية اعتماد النصوص واستخدامها

1. راجع الملف المرئي وأسماء المنشأة والخدمات والأسئلة والأجوبة، وحدد التعديلات المطلوبة لكل لغة.
2. املأ مرجع الاعتماد واسم المعتمد وتاريخه بعد المراجعة الفعلية؛ لا تُحوّل status إلى approved قبل ذلك.
3. على staging، استخدم المحتوى العربي كـpost_content والإنجليزي في حقلي `_adc_title_en` و`_adc_content_en` عبر محرر WordPress الذي توفره الإضافة. استخدم قالب الصفحة الافتراضي للمحتوى الجديد، وتحقق من العنوان الرئيسي وتباعد الأقسام.
4. احفظ الصفحة كمسودة أولًا. استبدال المحتوى المنشور الحالي يحتاج نسخة قبل التغيير ومقارنة؛ الحزمة لا تستبدله تلقائيًا.
5. الوصف المختصر بيانات تحريرية مقترحة، ولا يُفترض أنه يُنشر كـmeta description تلقائيًا. نصوص microcopy مرجع للإدراج بعد الاعتماد وليست إعدادات مطبقة الآن.
6. تحقق من تنفيذ shortcodes في اللغتين، وصحة الروابط والتواصل والمحتوى والجوال. ثم انشر النسخة المعتمدة وأعد preflight على staging.

## التنفيذ الحالي وحدوده

أُعدّت النصوص والقالب المنظم لبيانات المنشأة وورقة تفاصيل المركبات والمعاينة. لم تُنشأ سجلات أعمال أو أسعار أو VINs، ولم تُنشر صفحات أو يُعدّل المحتوى الحالي. لم تُعد كتابة النصوص القانونية أو إقرار امتثال؛ تبقى المسودات السابقة موضوع مراجعة مختص بناءً على تفاصيل المنشأة الفعلية.

المتبقي لإغلاق B: تأكيد real أو demo لنمط البيانات، استلام بيانات المنشأة والمخزون والسياسات، مراجعة اللغتين واعتمادهما. المرحلة C تتطلب عنوان الاستضافة المستهدفة وإتاحة بيئة staging؛ الملف المرئي المحلي ليس موقع staging ولا إثباتًا لـHTTPS.

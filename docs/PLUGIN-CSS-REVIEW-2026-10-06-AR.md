# مراجعة تنسيق Auto Dealership Core — 6 أكتوبر 2026

## النتائج والتعديلات

- كان تنسيق لوحة الإدارة محصورًا في مساحة العمل وصفحات التواصل؛ أضيف ملف `assets/css/admin.css` لتوحيد صفحات العمليات والمخزون والمبيعات والإعدادات والتقارير.
- تحسين التسلسل البصري للعناوين والمسافات والبطاقات، بألوان كحلية وزرقاء وخلفيات فاتحة وحدود هادئة.
- تنظيم حقول النماذج داخل البطاقات وتكييفها مع عرض الهاتف، وتحسين أزرار الإجراءات وحالات التركيز والحقول المقفلة.
- تحديث بطاقات مساحة العمل والأيقونات وتنسيق حالات العملاء مع مراعاة تقليل الحركة حسب إعدادات المستخدم.
- إضافة `assets/js/admin-layout.js` لاحتواء الجداول داخل منطقة تمرير أفقية قابلة للوصول بلوحة المفاتيح، مع إبقاء بنية الجدول الأصلية. المعرفات المعروضة داخل `code` تبقى باتجاه LTR دون تقطيع.
- تحميل التنسيق المشترك فقط عندما يتطابق معرّف شاشة الإدارة المسجلة مع صفحة الإضافة، وإضافة الفئة `adc-admin` لعزل القواعد. تحديث إصدارات ملفات التنسيق بحسب وقت تعديلها لتجاوز التخزين المؤقت.

## حدود النطاق

الواجهات العامة التي تنتجها الإضافة تعتمد على تنسيقات ثيم `car-dealer`، ولا توجد لها حزمة CSS عامة مستقلة داخل الإضافة. لم تُعدّل ملفات الثيم أو تصميم مستند عرض السعر في هذه المراجعة. ملف `typography.css` الحالي يفرض Tajawal على الموقع ولوحة الإدارة عمومًا؛ احتُفظ بهذا السلوك الموجود مسبقًا.

## التحقق

- فحص صحة PHP للملفين المعدلين وصحة JavaScript وفحص فروق الملفات.
- اختبار عزل التحميل بين صفحات الإضافة والشاشات الأخرى باستخدام بدائل لدوال ووردبريس.
- عرض نماذج HTML ممثلة للبطاقات والنماذج والجداول، مع CSS ووردبريس الفعلي، في Chrome بعرض 1440 و390 بكسل: التحقق من عدم تجاوز عرض الصفحة، والتمرير داخل الجداول، وخصائص الوصول، وعدم تكرار الأغلفة عند تشغيل المعالجة مجددًا.
- صور المعاينة وملفات التحقق المحلية داخل `.tmp/adc-css-review/`.

هذه معاينة لعناصر ممثلة، وليست مراجعة مرئية لكل شاشة تشغيلية داخل جلسة إدارة مسجلة الدخول. الجداول العريضة تحتاج إلى تمرير أفقي على الهاتف، ويعتمد احتواء الجداول التلقائي على JavaScript.

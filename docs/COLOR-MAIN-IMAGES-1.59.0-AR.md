# إدارة صور الألوان — 1.59.0

نُفّذ محليًا فقط، دون رفع إلى الاستضافة أو إنشاء حزمة ZIP.

## الإدارة

في محرر السيارة المرتبطة بأونكس، أُضيف قسم موحد **صور السيارة حسب اللون**:

- اختيار **لون العرض الافتراضي** أو إبقاء الاختيار تلقائيًا.
- بطاقة مستقلة لكل لون: صورة رئيسية صريحة، وصور إضافية قابلة للترتيب، وعدد الصور، وحالة تجهيز الصورة الرئيسية.
- زر **تعيين كرئيسية** على الصور الإضافية. ينقل الصورة الرئيسية السابقة إلى المعرض دون حذف ملفها.
- حد أقصى 20 صورة لكل لون: رئيسية و19 إضافية. عند وجود صور إضافية، يلزم اختيار رئيسية صالحة قبل الحفظ.
- فتح المحرر لا ينقل أو يمسح البيانات. المعرض القديم لكل لون يُعرض بأول صورة كرئيسية والبقية إضافية؛ تُحفظ الصيغة الصريحة عند حفظ الصفحة.

## العرض العام

يعتمد العرض على صور اللون نفسه فقط. عند غيابها يظهر تنبيه بعدم توفر الصور، دون استعارة صور من لون آخر.



## البيانات والحماية

- `_adc_color_galleries`: المعرض المتوافق مع الصيغة السابقة، والصورة الرئيسية في بدايته.
- `_adc_color_main_images`: معرّف الصورة الرئيسية لكل لون، منفصل عن ترتيب الصور الإضافية.
- `_adc_default_color`: مفتاح اللون المفضل، مرتبط بتعريف اللون المطابق لأونكس.
- تبقى معارض الألوان التاريخية غير المعروضة محفوظة. الحفظ من محرر أقدم لا يمسح الصورة الرئيسية أو اللون المفضل.
- فحص صلاحية تعديل السيارة والمرفقات، وحدود الصور، وصحة اللون الافتراضي، وفحص نسخة الحفظ والمعاملة والتدقيق الحالية مستمر.
- لم تتغير بيانات مخزون أونكس أو هيكل قاعدة البيانات أو روابط السيارات.

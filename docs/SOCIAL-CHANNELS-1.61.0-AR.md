# التواصل الاجتماعي والمشاركة — 1.61.0

التنفيذ محلي للمراجعة. لم يُرفع إلى الاستضافة، ولم تُنشأ حسابات اجتماعية أو تُنشر مشاركات خارجية أو تُستبدل روابط المعرض بروابط اختبار.

## الإدارة

- **الإعدادات ← التواصل الاجتماعي**: روابط الحسابات، تفعيل كل منصة، ظهورها في الفوتر وصفحة التواصل، الترتيب بالسحب أو بأزرار التحريك، واختيار ألوان الثيم أو ألوان المنصات.
- **المظهر ← تخصيص ← الشبكات الاجتماعية**: الإعدادات نفسها مع معاينة قبل النشر. ترتيب المنصات وحالات الظهور يتزامنان مع حالة التخصيص الحالية، بما فيها التغييرات غير المنشورة.
- **إعداد المنصة ← المظهر والتواصل**: رابط مباشر إلى الإدارة الكاملة. حقول فيسبوك وإنستغرام وواتساب القديمة تستمر في تعديل المصدر نفسه.

المنصات المدعومة: فيسبوك، إنستغرام، واتساب، X، تيك توك، سناب شات، يوتيوب، لينكدإن. لا تظهر منصة بلا رابط صالح. إدخال رابط لا يثبت ملكية الحساب؛ يُستخدم الرابط الذي يحدده الأدمن.

واتساب يستخدم رقمًا دوليًا، مع دعم تحويل الرقم السعودي الذي يبدأ بـ05. تعطيل أيقونة واتساب في قائمة الحسابات لا يعطل زر التواصل الخاص بالسيارة أو الرابط العائم.

## الواجهة

- أيقونات SVG محلية من مسارات ثابتة، بحجم بصري موحّد ودون خطوط أيقونات أو مكتبات اجتماعية خارجية.
- مساحة ضغط 44×44 بكسل، وتسميات عربية وإنجليزية، وتركيز واضح بلوحة المفاتيح، واسم المنصة عند المرور أو التركيز.
- ألوان الثيم هي الافتراضية. الألوان الاختيارية للمنصات تراعي الخلفيات الفاتحة والداكنة، مع سناب شات بالأصفر والأسود في نمط المنصات.
- احترام ألوان الفوتر المخصصة وتقليل الحركة. أيقونة واتساب نفسها مشتركة بين الأزرار والفوتر والتواصل والزر العائم، دون تغيير مواضع الأزرار العائمة.

## مشاركة السيارات والعروض

روابط واتساب وX وفيسبوك تحمل عنوان الصفحة ورابطها باللغة الحالية، مع ترميز معاملات الرابط مرة واحدة. أضيفت المشاركة لصفحة العرض أيضًا.

زر **نسخ الرابط** يستخدم Clipboard API ثم بديل النسخ المحلي؛ إن تعذرا يظهر حقل قابل للتحديد اليدوي ورسالة واضحة. يُعرض زر المشاركة الأصلية عندما يدعمها المتصفح. إلغاء المستخدم لا يعرض خطأ، وتعذر المشاركة يوضح إمكانية نسخ الرابط. روابط المشاركة الأساسية تظل موجودة دون JavaScript.

لا توجد مشاركة تلقائية: لا يحدث إرسال لمنصة خارجية إلا عندما يختار الزائر رابط المشاركة أو خدمة المشاركة من جهازه.

## البيانات والتوافق

- الروابط تستمر في `car_dealer_theme_settings`، بما فيها روابط فيسبوك وإنستغرام ورقم واتساب الحالية. أضيفت مفاتيح المنصات الأخرى إلى إعدادات المظهر القابلة للنقل.
- الترتيب والتفعيل وأماكن الظهور والنمط في `adc_social_preferences` بصيغة JSON موحّدة بين الداشبورد والتخصيص. نقل هذه التفضيلات المدخلة يكون مع قاعدة بيانات الموقع؛ الخيارات الافتراضية والأيقونات تأتي مع الإضافة.
- الحفظ الجزئي القديم يحافظ على الروابط والإعدادات غير التابعة له. لا يتطلب الإصدار ترحيل مخطط قاعدة البيانات.
- شاشة الإدارة تتحقق من الصلاحية وnonce وبصمة التعديل، وتحفظ الروابط والتفضيلات عبر معاملة وسجل تدقيق. التغييرات الناقصة أو المتزامنة تُرفض بدل فقد بيانات.
- قبول روابط HTTP/HTTPS التابعة للمنصة المعنية، وترقية HTTP إلى HTTPS، ورفض الحسابات المضمنة في الرابط والمنافذ والبروتوكولات غير المناسبة. لا تُجري عملية التحقق اتصالًا بالحساب الخارجي أو تحاول تسجيل الدخول إليه.
- تبقى روابط Twitter القديمة صالحة لحساب X. مسار المشاركة يستخدم `/intent/tweet` كما يظهر في [أداة النشر الرسمية لـX](https://publish.x.com/?query=https%3A%2F).

## التحقق المنفذ

- 44 فحصًا دون كتابة بيانات، تشمل الروابط والأيقونات والترجمة والترتيب والحفظ الجزئي وترميز المشاركة.
- 8 اختبارات حفظ فعلي ضمن قاعدة مؤقتة معزولة، تشمل الحفاظ على البيانات الأخرى، والتعديل المتزامن، والمدخلات غير الصالحة، والتراجع عند فشل التدقيق، ومنع الحفظ دون صلاحية.
- مراجعة 16 حالة عرض بين مقاسات الجوال والتابلت والكمبيوتر، واللغتين، والوضعين، مع اختبارات الإدارة والمعاينة في التخصيص دون نشر.
- اختبارات النسخ المرفوض وإلغاء المشاركة وتعذرها، والروابط دون JavaScript، وإمكانية الوصول عبر axe لقسم التواصل والمشاركة.

لم ترسل اختبارات المتصفح مشاركات فعلية أو طلبات عملاء أو رسائل بريد. انتهت اختبارات قاعدة البيانات بحذف قاعدة الاختبار وإيقاف خادمها المنفصل.

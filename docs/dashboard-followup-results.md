# استكمال مراجعة الداشبورد وتنفيذه

التاريخ: 7 أكتوبر 2026.

## التغييرات

- بحث وترقيم فعلي لطلبات التمويل واعتماد الخصومات واعتماد المبيعات. تعرض الصفحة 50 نتيجة، مع العدد الإجمالي وروابط الصفحات وحفظ البحث والتبويب أثناء الانتقال. تُضبط الصفحة غير الموجودة إلى آخر صفحة صحيحة.
- بحث وترقيم لقوائم الاحتجاز والصيانة، مع تطبيق نوع الحالة والبحث ونطاق الفرع قبل الحد والإزاحة. بقيت الواجهة القديمة `list_open()` متوافقة مع مستهلكيها، وأضيفت `open_page()` للواجهة المرقمة.
- ترتيب ثابت بمعرف السجل عند تساوي التوقيت، لتجنب تكرار أو إسقاط سجلات بين الصفحات.
- البحث يتعامل مع `%` و`_` كنصوص عادية، ويستخدم معاملات SQL. لا يسمح البحث لموظف المالية الذي يفتقد صلاحية المخزون باستنتاج VIN من النتائج.
- حفظ اعتماد الخصم أو البيع يعود إلى تبويبه الصحيح. أضيفت تسميات البحث بالعربية والإنجليزية.
- أداة CLI قرائية `tools/audit-dashboard-duplicates.php` تعطي أعدادًا مجمعة لمرشحي تكرار العملاء والعلامات وروابط الكتالوج دون كشف الأسماء أو أرقام الاتصال، ودون حذف أو دمج.

## الاختبارات المنفذة

| الاختبار | النتيجة |
|---|---|
| المجموعة التشغيلية المعزولة | 701 حالة ناجحة، وخروج العملية برمز 0؛ تشمل الاستلام والفحص والصيانة وتغيير الموقع وVIN والنقل بين الفروع وعمليات البيع والتمويل وصلاحيات الأدوار ونطاق الفروع والتراجع عند فشل التدقيق واختبارات HTTP |
| مجموعة الطوابير والإدارة الجديدة | 35 حالة ناجحة، وخروج العملية برمز 0؛ بيانات تتجاوز 100 سجل وفرع آخر وحسابات موظفين فعلية على قاعدة معزولة |
| متصفح Chrome المحلي | 148 فحصًا ناجحًا؛ تشمل إرسال البحث على طوابير التمويل والخصومات والمبيعات والاحتجاز والصيانة، والصفحات السابقة والتخصيص وعرض الهاتف |
| PHP وفروق الملفات | فحص صياغة الملفات الجديدة والمتغيرة وفحص فروق Git ناجحان |
| الترجمة | 1604 ظهورات نصية و173 تسمية ديناميكية لها ترجمة |

مجموعة الطوابير تتأكد من تغطية 121 سجلًا عبر ثلاث صفحات دون تكرار، ومنع تسريب بيانات الفرع الآخر، والبحث النصي الحرفي، وعدم توسيع النتائج بمدخلات شبيهة بـSQL، ومن صحة العرض الفعلي للخصومات والمبيعات والتمويل.

اختبارات الإدارة ترسل طلبات HTTP مع ملفات ارتباط موظفين وnonces حقيقية إلى معالجات `admin_post` الإنتاجية داخل الموجّه التجريبي المعزول. تؤكد رفض nonce الاستلام غير الصحيح، ورفض موظف المالية والفرع الآخر، وحفظ الاستلام وقائمة الفحص وحركة الموقع وتصحيح VIN، وصحة وجهة العودة بعد الحفظ. لم يُستخدم المتصفح لإرسال هذه الإجراءات إلى بيانات الموقع المحلي؛ المتصفح المحلي يختبر البحث والعرض فقط.

## نتيجة مراجعة التكرار المحلية

أعادت الأداة صفرًا لكل مجموعات التكرار وروابط المنشورات المكررة أو غير الصالحة. لكن المصدر المحلي يحتوي حاليًا على **0 عملاء و0 مركبات تشغيلية و0 علامات نشطة**؛ لذلك هذه نتيجة على قاعدة خالية من السجلات المعنية، وليست إثباتًا لسلامة قاعدة ممتلئة.

مراجعة العملاء تستخدم الاتصال المخزن بعد إزالة الفراغات وتوحيد حالة الحروف. لا تطابق صيغ الهاتف المحلية والدولية ولا تقرر الدمج تلقائيًا؛ قد يشترك أفراد أو جهات في بيانات اتصال صحيحة. يجب إعادة تشغيل الأداة ومراجعة المرشحين عند تحميل البيانات الفعلية.

## العزل والتنظيف

رفض حساب قاعدة الموقع إنشاء قاعدة اختبار جديدة، لذا جرى تشغيل MariaDB مستقل على المنفذ المحلي 33319 بمجلد بيانات منفصل، ثم تشغيل المجموعتين عبر `database-runner.php --isolated 33319`. قواعد الاختبار العشوائية أُزيلت بعد كل تشغيل؛ لم تتصل سيناريوهات الاختبار بقاعدة المصدر. أُزيلت جلسة المتصفح المؤقتة وأُوقف الخادم المنفصل.

رفضت سياسة الأدوات حذف مجلد ملفات الخادم التجريبي برسالة `blocked by policy`. بقي المجلد `.tmp/dashboard-db-20261007` محليًا، مع الخادم متوقفًا وقواعد السيناريوهات محذوفة. محفوظات التحقق تحت `.tmp/dashboard-full-suite.log` و`.tmp/dashboard-queue-suite.log`.

## إعادة التشغيل

على خادم MariaDB تجريبي فارغ منفصل:

```powershell
C:/xampp/php/php.exe wp-content/plugins/auto-dealership-core/tests/database-runner.php --isolated <test-port>
$env:ADC_DASHBOARD_ONLY = '1'
try {
    C:/xampp/php/php.exe wp-content/plugins/auto-dealership-core/tests/database-runner.php --isolated <test-port>
} finally {
    Remove-Item Env:/ADC_DASHBOARD_ONLY
}
```

الفحص القرائي للمصدر:

```powershell
C:/xampp/php/php.exe tools/audit-dashboard-duplicates.php
```

بقيت طوابير التسليم ومحدد البيع داخل نموذج إنشاء طلب التمويل خارج إضافة الترقيم لهذه الدفعة؛ هذه الدفعة غطت الطوابير المحددة في طلب الاستكمال: التمويل والاعتمادات والصيانة.

# توحيد خطوط النظام على Tajawal — 4 أكتوبر 2026

## نتيجة المراجعة والتطبيق

كان متغير الخط في القالب يستخدم Tahoma/Arial/Segoe UI، وكان عرض السعر المطبوع يحدد Tahoma مستقلًا. توجد أيضًا تعريفات Arial/sans-serif داخل أنماط jQuery UI وSelect2 التابعة لـMeta Box؛ عولجت عبر CSS النظام دون تعديل ملفات الإضافة الخارجية أو نواة WordPress.

أصبح خط النصوص Tajawal في القالب والإضافة والموقع والإدارة وتسجيل الدخول والمحرر الكتلي والكلاسيكي وعرض السعر والطباعة. حُفظت الخطوط الخاصة بالأيقونات، لأنها تمثل رموزًا وليست نصوص واجهة.

## الملفات

- `wp-content/plugins/auto-dealership-core/assets/fonts/tajawal/`: سبعة ملفات خط محلية للأوزان 200، 300، 400، 500، 700، 800، 900 مع ترخيص SIL OFL الأصلي؛ المصدر مستودع Google Fonts الرسمي كما ورد في README المجاور.
- `assets/css/typography.css`: تعريف @font-face المحلي والمتغيرات وقواعد النصوص والنماذج والإدارة والمحرر وMeta Box. font-display: swap يبقي النص ظاهرًا أثناء التحميل.
- `src/Core/Typography.php`: تحميل واحد عبر wp_enqueue_scripts وadmin_enqueue_scripts وlogin_enqueue_scripts وenqueue_block_assets، وإضافة CSS إلى mce_css للمحرر الكلاسيكي.
- `wp-content/mu-plugins/autobrands-typography.php`: محمّل عام يجعل الخط متاحًا أيضًا عند تعطيل إضافة المعرض مع بقاء ملفاتها مثبتة. يحمي bootstrap من التكرار ولا يغير المستخدمين أو الخيارات أو قواعد الأعمال.
- متغير القالب في `_variables.css` أصبح Tajawal، وأُعيد توليد `main.css` من المصادر، مع إبقاء تغييرات المستخدم السابقة في بقية CSS.
- `QuoteDocument.php` يربط stylesheet الخط في المستند المستقل ويستخدم Tajawal في الطباعة.
- أداة حزمة الإصدار تشمل محمّل MU وملفات الخط ضمن وحدة التوزيع؛ يلزم نقل ملف MU إلى مساره مع القالب والإضافة. لم تُبنَ حزمة إصدار جديدة في هذه المهمة.

## التحقق

- نجحت فحوص صياغة ملفات PHP المعدلة وJavaScript، و`build-css.js --check` و`git diff --check`.
- التحقق أثناء تحميل WordPress أثبت تسجيل واجهات الموقع والإدارة وتسجيل الدخول والمحررين وإدراج stylesheet دون تكرار bootstrap.
- نجحت **5 فحوص متصفح لصفحة مستقلة** تحمل أنماط WordPress الأصلية: تحميل الأوزان السبعة فعليًا، الخط المحسوب لعناصر النص والنماذج والإدارة والمحرر وMeta Box، سلامة Dashicons وشريط الإدارة، ومحاكاة print media، وعدم وجود أخطاء أو موارد مفقودة.
- نجحت **82 حالة قبول للموقع المحلي** بعد عودة استجابته، منها تحميل الأوزان السبعة وتحقق font-family للنصوص والتحكمات، تسجيل الدخول والأيقونات، وRTL/LTR والمقاسات الموجودة في المجموعة. تشغيل Chrome تم في نطاق التنفيذ الموافق عليه سابقًا.
- أول محاولة الموقع توقفت بـPage.navigate timeout أثناء عدم استجابة صفحات WordPress؛ ملفات CSS كانت متاحة. لم تُعد تشغيل خدمات المصدر أو إصلاح قاعدة البيانات؛ نجح الفحص الكامل لاحقًا بعد استجابة الموقع.

## إعادة التحقق

```powershell
node wp-content/themes/car-dealer/build-css.js --check
$env:ADC_TYPOGRAPHY_ONLY = '1'
node wp-content/plugins/auto-dealership-core/tests/browser-bilingual-site.cjs
Remove-Item Env:\ADC_TYPOGRAPHY_ONLY
node wp-content/plugins/auto-dealership-core/tests/browser-bilingual-site.cjs
```

صفحة أنماط الإدارة المستخدمة في التحقق هي fixture محلية وليست جلسة مسؤول فعلية، والاختبار لا يدّعي مراجعة بصرية لكل إضافة خارجية أو كل شاشة إدارية. تحميل hooks والمحررين ثبت برمجيًا، أما المصدر المطبوع فتم التحقق من ربط الخط وصياغته مع محاكاة الطباعة في fixture، وليس إصدار PDF جديد لعرض سعر حقيقي.

لم تتغير بيانات الأعمال أو السياسات أو المحتوى التحريري. لا يعتمد الخط على خدمة خط خارجية أثناء تشغيل الموقع.

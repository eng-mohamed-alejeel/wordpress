# قبول إصدار الداشبورد الإداري 1.66.0 — AD-047

## نطاق الإصدار

هذه الدفعة توثيق وإصدار فقط. لا تضيف تغييرًا وظيفيًا جديدًا إلى الداشبورد. الحزمة المستخدمة للمراجعة تشمل تغييرات AD-040 إلى AD-046 الحالية في شجرة العمل، وتظل الحزمة مراجعة حتى تُراجع على staging ويُعتمد الإصدار.

## بوابة القبول

| البند | الدليل | الحالة |
|---|---|---|
| PHP syntax | فحص `php -l` للملفات المعدلة | ناجح — 19 ملفًا |
| JavaScript syntax | `node --check` لاختبارات المتصفح | ناجح — 9 ملفات |
| الصلاحيات والنطاق | اختبارات access governance وmobile roles | ناجح — 880 تحققًا متصفحيًا |
| الوصولية | Arabic/English، RTL/LTR، light/dark، axe | ناجح — 295 تحققًا و24 مسح axe دون مخالفات |
| الألوان | `browser-admin-color-contract.cjs` | ناجح — 96 تحققًا |
| التشخيص | `browser-admin-diagnostics.cjs` قراءة فقط | ناجح — 56 تحققًا |
| الأداء | baseline وقياس الاستعلامات الموثق | موثق في `docs/artifacts/admin-dashboard-performance-baseline-1.66.0/` |
| الحزمة | ZIP، manifest، SHA-256، منع `wp-config.php` والاختبارات | ناجح لحزمة المراجعة — 387 ملفًا |
| التثبيت المعزول | WordPress/MariaDB منفصلان | ناجح عبر قاعدة `adc_verify_*` مؤقتة؛ rehearsal بخادم MariaDB فارغ مخصص ما زال مطلوبًا |
| screen reader | اختبار يدوي فعلي على staging | إجراء يدوي مطلوب |
| staging | حسابات وأدوار مماثلة للإنتاج | إجراء يدوي مطلوب |

## الأوامر المعتمدة

```powershell
php tools\release-preflight.php --inspect
php tests\database-runner.php --isolated 33381
powershell -ExecutionPolicy Bypass -File tools\build-release-package.ps1 -ReviewWorkingTree
```

يُمنع تشغيل `--isolated` على خادم يحتوي قواعد تطبيق؛ الأداة ترفض ذلك وتزيل فقط قاعدة `adc_verify_*` التي أنشأتها. لا تُستخدم حزمة `review` للنشر النهائي قبل تثبيت commit معتمد وإعادة بناء الحزمة من commit نظيف.

## مصفوفة المرور اليدوي

يجب أن يراجع مالك المنتج أو مسؤول الجودة، بحسابات منفصلة، الأدوار: مسؤول النظام، المدير العام، مدير المبيعات، المبيعات، المالية، المخزون، المشتريات، التسليم، التسويق، الدعم، والتشغيل. لكل حساب تُراجع الصلاحيات المباشرة، النطاق الشخصي/الفرعي/المتعدد/الشامل، العربية والإنجليزية، الوضعين الفاتح والداكن، والعروض 320 و390 و768 و1440 بكسل.

## قرار الإصدار

لا يُعلن الإصدار جاهزًا إذا وُجد فشل آلي، اختلاف غير مفسر في الأداء، فشل وصول مباشر أو cross-branch، أو لم يُنفّذ اختبار قارئ الشاشة ومراجعة staging. عند الفشل، تحفظ النتيجة مع رقم الدفعة وتُستخدم الحزمة السابقة وإجراء الرجوع الموثق.

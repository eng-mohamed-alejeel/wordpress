## 4. إدارة دورة الوثيقة

1. ينشئ مالك السياسة مسودة ويحدد النطاق والسبب.
2. يعين مراجعًا مناسبًا للموضوع ومراجعًا مستقلًا عند الحاجة.
3. يسجل المراجع ملاحظاته ويرفض النشر عند نقص الأدلة أو بقاء شرط مفتوح.
4. يوافق صاحب التفويض؛ لا يعتمد المنشئ استثناءه أو قراره الشخصي وحده.
5. تحفظ نسخة مؤرخة ومراجعتها وسجل التغييرات، وتوزع النسخة النافذة على المعنيين.
6. يراجع المالك التنفيذ والأدلة والاستثناءات عند الموعد المحدد أو تغير النشاط/المخاطر/الأنظمة.
7. يسحب الإصدار المستبدل من الاستخدام مع الاحتفاظ بسجل وفق سياسة المنشأة.

## 5. الحقول التي تتطلب قرارًا محليًا

لا تضع المكتبة قيمًا افتراضية لهذه العناصر:

- حدود الخصم أو الشراء أو الصرف أو الائتمان أو الاسترداد.
- عملة القياس ومستوى تجميع العمليات المرتبطة.
- مدد حفظ البيانات والسجلات والمرفقات.
- دورية مؤشرات الأداء وأهدافها وحدود التنبيه.
- المدد القانونية أو التعاقدية وموقع استضافة البيانات.
- أصحاب الاعتماد والاستثناءات والبدائل.

إذا كانت القيمة غير معتمدة، تبقى فارغة/غير محددة وتمنع الواجهة التقنية من عرضها كقيمة نافذة.

# نموذج مرجعي محايد للوظائف والمسؤوليات

## 1. مفاهيم يجب فصلها

| المفهوم | معناه | مثال عام |
|---|---|---|
| وظيفة تنظيمية | نوع المسؤولية المطلوب إنجازها | الرقابة المالية |
| منصب/مسمى وظيفي | ترتيب المنشأة للوظيفة وتعيين شخص لها | مسمى يختاره صاحب العمل |
| مسؤولية/عملية | نتيجة أو خطوة عمل محددة ومالكها | مراجعة طلب قبل اعتماده |
| دور نظام | مجموعة مهام رقمية يجمعها النظام | دور يحدده كتالوج المنتج |
| قدرة تقنية | فعل واحد يمكن السماح به أو منعه | عرض تقرير أو تعديل حالة |
| نطاق الوصول | السجلات أو الفروع أو الحقول التي ينطبق عليها الفعل | نطاق يحدده النظام والخادم |

لا يعني تشابه أسماء منصب ودور نظام أنهما متكافئان. ولا يمنح هذا النموذج سلطة تقنية بمجرد وجود مسمى في الهيكل.

## 2. وظائف تنظيمية مرجعية

هذه قائمة وظائف محتملة، وليست هيكلًا إلزاميًا. يجوز جمع الوظائف المتوافقة أو الاستعانة بمصادر خارجية بحسب الحجم والمخاطر، مع عدم جمع مهام متعارضة دون ضابط تعويضي معتمد.

| الوظيفة المرجعية | الغرض والمسؤولية العامة | أمثلة نتائج |
|---|---|---|
| الحوكمة/المالك | تحديد التفويض والاستراتيجية ومراقبة الإدارة العليا | قرارات موثقة، تفويضات محددة، متابعة المخاطر |
| القيادة التنفيذية | تحويل التوجهات المعتمدة إلى خطط وتشغيل ومساءلة | أهداف تشغيلية، تخصيص موارد، معالجة انحرافات |
| مالك المجال | تحديد احتياج المجال وإجراءات العمل وقبول النتائج | سياسة مجال، تعريف مالك عملية، مؤشرات ومخاطر |
| العمليات/تنفيذ الخدمة | إنجاز العمل وتسجيل الطلبات والنتائج | معاملات مكتملة وأدلة تنفيذ |
| علاقات العملاء/المبيعات | إدارة التواصل والفرص والالتزامات التجارية | سجل تعامل، عرض موثق، متابعة خدمة |
| إدارة الموارد أو الأصول | حفظ السجلات والحيازة والحركة والجرد للأصول ذات الصلة بالنشاط | مطابقة، سجلات مواقع، معالجة فروقات |
| المالية/المحاسبة | التحقق المالي والتسجيل والتحصيل والتسويات والتقارير | قيود ومطابقات وتقارير معتمدة |
| الموارد البشرية/الإدارة | دورة حياة العاملين والاحتياجات الإدارية وفق التفويض | تعيينات وتغييرات وظيفية وسجلات موارد |
| التقنية/إدارة النظام | تشغيل المنصة والحسابات والتغييرات التقنية | إعدادات آمنة، تغييرات موثقة، إدارة هوية |
| الأمن/الخصوصية/البيانات | مراجعة المخاطر والحاجة إلى البيانات والوصول والاحتفاظ | تقييمات وضوابط ومراجعات وصول |
| الرقابة/التدقيق | فحص مستقل للالتزام والأدلة والاستثناءات | نتائج مراجعة وإجراءات تصحيحية |

قد يؤدي شخص واحد أكثر من وظيفة في المنشآت الصغيرة، لكن يجب أن تسجل الوظائف المجمعة وأسبابها وحدودها. لا تعد الرقابة مستقلة إذا راجع الشخص قراره أو العملية التي نفذها دون مراجعة مستقلة مناسبة.

## 3. أسئلة تصميم الهيكل

أجب عن كل سؤال بوصفه مدخلًا محليًا للمنشأة:

- ما الخدمات أو المنتجات التي تقدمها المنشأة، ولمن؟
- ما العمليات الأساسية والداعمة، ومن يملك كل عملية؟
- ما الوظائف التي يجب أن تكون مستقلة بسبب قيمة الأصل أو حساسية البيانات أو أثر القرار؟
- ما المواقع أو الوحدات الداخلة في النطاق، وكيف تنظم العلاقات بينها؟
- ما الوظائف التي يمكن دمجها مؤقتًا، وما الحدث الذي يستدعي فصلها لاحقًا؟
- من يعتمد الهيكل والتفويض، ومن يراجعه عند تغير النشاط؟
- كيف تعالج المنشأة الشواغر، البدائل، تضارب المصالح، والاستثناءات؟

## 4. مصفوفة ربط الهيكل بالعمل

تُستكمل لكل وظيفة أو عملية ذات أثر مهم. لا تستخدم إجابة مفترضة من هذا القالب بوصفها قرارًا.

| المجال/العملية | الوظيفة المالكة | المنفذ | المراجع | المعتمد | دليل الإتمام | نطاق التطبيق | الاستثناء/التصعيد |
|---|---|---|---|---|---|---|---|
| `[اسم العملية]` | `[وظيفة]` | `[وظيفة]` | `[وظيفة مستقلة عند الحاجة]` | `[مفوض]` | `[سجل/وثيقة]` | `[موقع/سجل/فئة]` | `[قاعدة معتمدة]` |

لكل صف:

- عين مسؤولًا واحدًا عن النتيجة، حتى لو اشترك أكثر من منفذ.
- ميز بين طلب العملية وتنفيذها واعتمادها ومراجعتها.
- اذكر نطاق السجلات والبيانات؛ لا يكفي تحديد اسم الدور.
- أشر إلى متطلبات الاعتماد الخارجي أو القانوني بدل اختراعها.
- عند عدم انطباق وظيفة، سجل السبب والضابط البديل.

## 5. إدارة التغيير التنظيمي

عند تعيين أو نقل أو إنهاء مسؤولية شخص:

1. يعتمد مالك الجهة التغيير وتاريخ نفاذه.
2. تحدّث أوصاف الوظائف والتفويضات وتبعيات الموافقات.
3. تراجع حسابات النظام ونطاقاتها وفق المهام الجديدة، لا وفق المسمى القديم.
4. تنقل المعاملات والعهد والسجلات إلى مالك بديل مع توثيق الاستلام.
5. تراجع تعارضات الواجبات بعد التغيير.
6. تحفظ نسخة سابقة وأثر التغيير وتاريخه ومراجعه.

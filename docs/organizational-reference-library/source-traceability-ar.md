# مصفوفة تتبّع مصادر مكتبة الوظائف والحوكمة

## 1. الغرض والنطاق

توضح هذه المصفوفة كيف استُخدمت المواد المصدرية الموجودة في `docs/الهيكل الوظيفي والمهام والمسؤوليات/` لبناء [المكتبة المرجعية المحايدة](./README.md). الملفات الأصلية لم تُعدّل. وجود مادة في المصدر لا يعني اعتمادها أو ملاءمتها لكل منشأة.

أنواع التصنيف:

- **عام:** مبدأ أو بنية قالب قابلة للتطبيق عبر قطاعات بعد مواءمتها.
- **قطاع سيارات:** إجراء أو مثال مرتبط بتجارة المركبات، يُستخدم فقط مع نشاط مناسب.
- **قرار منشأة:** قيمة أو مسمى أو حد أو هيكل لا ينسخ إلا بعد قرار المنشأة المخولة.
- **ولاية قضائية/تخصصية:** مادة تخضع لمراجعة نظامية أو ضريبية أو تعاقدية محلية.
- **مستبعد من المرجع العام:** لا يُنقل لأنه خاص بالجهة المصدرية أو غير مثبت أو لا يصلح كتوصية عامة.

## 4. نقاط تحتاج قرارًا أو مراجعة قبل إعادة الاستخدام

1. **حالة المصدر:** أسماء الوثائق تشير إلى مسودات أو نسخ مقترحة. لا تُعامل كسياسات أو تفويضات معتمدة إلا بوجود سجل اعتماد مستقل صحيح.
2. **الأرقام والمستويات:** أي أرقام مالية أو نسب أو أيام أو مستهدفات هي بيانات سياقية/مقترحة في مادة المصدر، وليست افتراضات منتج. يعاد تحديدها بحسب المنشأة والسوق والمخاطر والعملة وصاحب التفويض.
3. **القوانين والعقود:** كل إشارة إلى قانون أو ضريبة أو جمارك أو فوترة أو متطلب رسمي محلي تحتاج تحققًا من مصدرها الحالي ومراجعة المختص في نطاق المنشأة.
4. **التداخل والتكرار:** قد تعيد أدلة مختلفة عرض المبدأ أو العملية نفسها بصياغة أو تفصيل مختلف. تجمع المكتبة القاعدة المشتركة، وتحيل تفاصيل التنفيذ القطاعية إلى الحزمة، ولا تخفي أي اختلاف يحتاج قرار مالك العمل.
5. **قابلية التطبيق:** لا ينشأ منصب أو لجنة أو KPI أو إجراء لمجرد ظهوره في المصدر. يختار مالك المنشأة ما ينطبق ويوثق ما استبعده عند الحاجة.
6. **الإنفاذ البرمجي:** وجود دور أو اعتماد في الوثيقة لا يثبت أن WordPress أو الإضافة يفرضه. يلزم ربط خادمي واختبار قبول ورفض لكل حالة تقنية.
7. **النسخ الثنائية:** لم تُجرَ مقارنة تحريرية شاملة لكل DOCX مقابل PDF؛ قبل إصدار حزمة رسمية، يراجع مالك الوثيقة النسخة المعتمدة ويثبت رقمها وتاريخها.

## 5. حدود ما أنجزته المصفوفة

المصفوفة مراجعة تتبّع على مستوى الملفات والمحاور، وليست تدقيقًا قانونيًا أو اعتمادًا لأصل الوثائق، ولا تحليلًا نصيًا لكل جدول وخلية ومرفق. وهي لا تفترض أن محتوى المصدر كامل أو صحيح أو محدث. التوسع إلى ترحيل شامل لكل بند يتطلب تثبيت نسخة مصدر معتمدة وإجراء مراجعة تحريرية/موضوعية من مالكها.

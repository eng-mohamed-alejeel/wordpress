# لوحة العمل التشغيلية وتوحيد التنقل — 1.62.0

نُفذ بندا المستخدم: تطوير صفحة **مساحة العمل داخل الإدارة** وتوحيد مداخل هامش الربح ومستندات أونكس. الصفحة الرئيسية العامة للموقع ليست نطاق هذا التغيير.

## السلوك الجديد

تسبق روابط الوحدات لوحة تشغيل للقراءة فقط، تعرض القوائم المسموحة حسب الدور والفروع الحالية. يمكن اختيار فرع مسموح وفترة اليوم أو آخر 7 أو 30 يومًا للفرص الجديدة. تبقى بقية المؤشرات للحالة الحالية، ويوضح النص ذلك صراحةً. التاريخ المعروض بحسب توقيت WordPress، وتتحول بداية اليوم المحلي إلى UTC عند البحث.

| القائمة | ما يدخل في العدد |
|---|---|
| متابعات مستحقة | فرص غير won/lost لها next_action_at مستحق؛ ملكية الموظف أو نطاق مدير الفرع |
| فرص جديدة خلال الفترة | مرحلة new وتاريخ إنشاء داخل الفترة المحلية المحددة |
| خصومات تنتظر اعتمادك | طلب pending وعرض pending_discount غير منتهي وغير مرتبط ببيع، ليس طلب الموظف نفسه، وضمن مستوى اعتماده |
| مبيعات تنتظر مراجعتك | pending_approval داخل الفرع، ليست مملوكة للمراجع نفسه |
| حجوزات تنتهي خلال 6 ساعات | confirmed، لم تنته بعد وتنتهي خلال 6 ساعات؛ الفرع والمالك وفق سياسة عروض الأسعار |
| حجوزات منتهية تنتظر المعالجة | confirmed مع expires_at سابق أو مساوٍ للوقت الحالي، ولم تعالجها مهمة الانتهاء بعد |
| دفعات تنتظر مراجعتك | pending وبيع pending_approval/approved، والمراجع ليس مسجل الدفعة ولا مالك البيع |
| عربون ينتظر مراجعتك | pending لحجز confirmed غير منتهٍ، والمراجع ليس المسجل ولا مالك الحجز |
| تمويل ينتظر قرارك | submitted/under_review، ولم يقدمه المراجع نفسه |
| تسليمات قيد التجهيز | preparing/vin_confirmed/approved لبيع approved؛ لا يعني ذلك اكتمال شروط إطلاق المركبة |

لا تُعرض جميع القوائم لكل شخص. عرض المالية مشروط بصلاحياتها، ولا تحتوي اللوحة على مبالغ أو تكاليف أو بصمات تدقيق أو ملاحظات داخلية. المؤشر ليس تصريح اعتماد: تبقى خدمات الأعمال المرجع النهائي للصلاحيات والحالة والمبالغ والتزامن والمستندات.

كل بطاقة تفتح قائمة داخل مساحة العمل تستخدم **مصدر SQL وشروط الفرع والملكية والفلاتر نفسها** التي استُخدمت للعدد. القائمة مرتبة حسب الوقت ثم المعرّف وتعرض 20 سجلًا مع تنقّل يحفظ الفلاتر؛ لا تقف عند أول 20/100 سجل. قد تتغير الأعداد عند تحديث موظف آخر للبيانات بين الطلبات؛ لا تُقفل معاملات الأعمال لتثبيت شاشة متابعة.

تفتح أسطر الأعمال السجل في شاشته التشغيلية الحالية. أُضيف اختيار مباشر مقيد للصلاحيات عبر discount_id وsale_id وfinance_id وdeposit_id عند الحاجة، دون توسيع نطاق القراءة أو الكتابة. بقيت بقية روابط التفاصيل الحالية كما هي.

## الخطأ والفراغ وعزل البيانات

- فشل الاستعلام يظهر «تعذر التحميل» وعلامة — بدل عدد صفر مضلل، وفشل قائمة التفاصيل يظهر تنبيهًا.
- المستخدم دون فرع نشط يرى تفسيرًا واضحًا ونتيجة مقيدة؛ لا يعرض فرعًا افتراضيًا غير مخول.
- اختيار فرع أو نوع عمل غير مخول عبر URL يرفض تحميل الملخص دون إظهار البيانات أو SQL.
- لا توجد HTML أو نتائج مشتركة مخزنة بين الموظفين، ولا مهام تلقائية أو عمليات حفظ لمجرد تحميل الملخص.
- دعم RTL/LTR وعناوين وأسماء حقول واضحة وتحديد البطاقة الحالية. الجدول الصغير قابل للتمرير والتركيز بلوحة المفاتيح مع إرشاد على الجوال.

## التنقل الموحد ومستندات أونكس

- أصبح `adc-profit-margin` وجهة واحدة في عقد Navigation تحت **إعدادات المنصة**، بصلاحية manage_options، وتظهر منه البطاقة والقائمة معًا.
- أصبح `adc-onyx-documents` وجهة واحدة تحت **المالية**، بنفس سياسة قراءة الأرشيف القائمة: الإدارة أو عرض المالية أو اعتماد البيع.
- أُزيل تسجيل القائمتين المنفصل خارج العقد، مع الحفاظ على slugs وروابط admin.php السابقة وإجراءات الرفع والتنزيل والحفظ.
- الصفحة الجذرية لمستندات أونكس تعرض الآن **قائمة مبيعات ضمن نطاق المستخدم**، مع العميل ورقم المخزون والحالة وعدد المستندات، وبحث آمن وتنقّل من 20 سجلًا. لا يحتاج المستخدم تخمين رقم بيع.
- رابط تفاصيل البيع يبقى `page=adc-onyx-documents&sale_id=...`، مع عودة إلى قائمة المبيعات. صلاحيات التفاصيل ورفع PDF والتحقق من بصمته ومطابقة المستند لا تتغير.

لا يعني عرض عدد المستندات صحة الفاتورة؛ تستمر خدمة المطابقة الحالية في التحقق من المرجع والبصمة والمبالغ. ولا تسجل قائمة الأرشيف دفعة أو استردادًا.

## التحقق وطريقة الإعادة

اختبارات القبول في `tests/workspace-overview-scenarios.php` و`workspace-overview-http.php` و`browser-workspace-overview.cjs`. تعمل عبر مشغّل قاعدة مستقلة فقط، ببيانات عملاء وموظفين وفروع ومعاملات صناعية.

```powershell
$env:ADC_WORKSPACE_ONLY='1'
$env:ADC_WORKSPACE_BROWSER='1' # اختياري؛ يتطلب Chrome وplaywright-core مثبتين محليًا
try {
    & C:/xampp/php/php.exe wp-content/plugins/auto-dealership-core/tests/database-runner.php --isolated 33369
} finally {
    Remove-Item Env:ADC_WORKSPACE_ONLY
    Remove-Item Env:ADC_WORKSPACE_BROWSER
}
```

يجب أن يكون 33369 خادم MariaDB مستقلًا وفارغًا على loopback، وليس قاعدة الموقع. `--isolated` لا يقرأ wp-config.php الخاص بالموقع؛ يرفض الخادم الذي يحتوي قواعد تطبيق ويزيل قاعدة الاختبار في finally. خادم HTTP المؤقت مقيد بـloopback ومفصول عن Apache.

أضيفت مهمة `workspace` في CI مع خدمة MariaDB مستقلة لتشغيل قبول النموذج والقائمة وروابط HTTP. الاختبارات المحلية للمتصفح تستخدم CSS التشغيلية مع إطار عرض محايد، وليست محاكاة كاملة لكل إضافات WordPress أو كل لوحة استضافة؛ يلزم smoke على بيئة الاستضافة بعد التحديث. لم تُنفذ عمليات على قاعدة الموقع الحالية أثناء قبول هذه الميزة.

هذا الإصدار ينفذ ADM-01 وADM-02 من خطة لوحة الإدارة في نطاق المؤشرات والقوائم أعلاه. لا يفعّل مزودًا خارجيًا ولا يكمل مخزونًا أو سياسات تجارية نيابة عن صاحب الموقع، ولا يعالج بقية موانع الإطلاق. القوائم تعتمد على البيانات الفعلية؛ وجود صفر يبقى نتيجة صحيحة عندما لا توجد أعمال مؤهلة.

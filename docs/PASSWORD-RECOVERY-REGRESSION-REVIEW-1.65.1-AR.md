# مراجعة عدم التراجع — 1.65.1

## ما وجدته المراجعة وأصلحته

1. كانت وجهة الاستعادة تحتفظ بقسم الحساب، لكنها قد تفقد معرّف المحادثة أو التقييم. أصبحت الروابط والنماذج ورسالة الاستعادة والتحويلات تحتفظ بالمعرّف الرقمي المناسب للقسم. لا يُقبل عنوان خارجي، ولا تتحول هذه المعرّفات إلى إذن لقراءة سجلات حساب آخر.
2. نافذة إعادة المصادقة داخل محرر WordPress تُنشئ رابطها باستخدام `wp_login_url` ثم تضيف `interim-login`. تحويل الرابط إلى الصفحة المخصصة كان قد يمنع إكمال التواصل مع المحرر. أصبح طلب النافذة المضمنة يعود إلى مسار WordPress الخاص بهذه النافذة، مع اللغة المطلوبة، دون حلقة تحويل. تبقى صفحات الحساب العادية مخصصة.
3. أُغلقت جلسات المتصفح الخاصة بالأجزاء المكتملة قبل فحوص المحادثات ذات الجلستين. لم تُعدَّل مهلة الأربع ثواني أو تأكيدات مؤشر الكتابة أو تنفيذ المحادثات.

## الحفاظ على الموجود

- قورنت كتلة شروط كلمة المرور في `HEAD` بالمكوّن المشترك الجديد؛ المحتوى مطابق كما هو، دون إسقاط شروط أو أدوات. حافظ JavaScript على محدد حقل التأكيد القديم وأضاف دعم الحقل الجديد فقط.
- لا توجد ملفات محذوفة ضمن الفرق. لم تُعدّل مصادر المخزون أو التسعير أو الفواتير أو المبيعات أو الحجوزات في هذا التغيير، ولا مخطط قاعدة البيانات؛ يظل المخطط `1.25.0`.
- التحقق من كلمة المرور الجديدة ومفاتيح الاستعادة ما زال يعتمد على WordPress، وتبقى الحسابات المعلقة غير مفعّلة بعد تغيير كلمة المرور.
- تستخدم جميع الاختبارات قواعد مؤقتة على خادمي اختبار منفصلين، مع منع البريد الفعلي. لم تُستخدم قاعدة الموقع الأصلية في الاختبارات، ولم تُعدّل بيانات الحسابات الحقيقية أو ملفات رفع المستخدمين.
- طوبقت ملفات ZIP مع المصدر، وفُحص خلو الحزم من ملفات الاختبار وإعدادات قاعدة البيانات والأسرار.

## نتائج التحقق النهائي

نجحت المجموعات التالية، وانتهت اختبارات قواعد البيانات والحزم برمز خروج صفر:

- 282 فحص متصفح للحزمة العامة، بما فيها التسجيل والتأكيد والاستعادة والمحادثات ومؤشر الكتابة والمستندات الخاصة.
- 101 فحص لواجهة الحساب، يشمل العميل والموظف والأدمن والحساب الخالي من البيانات، وعزل الملخصات والتنقل.
- 61 فحصًا مخصصًا للاستعادة والروابط والوجهات ونافذة إعادة المصادقة والخروج.
- 230 فحص قاعدة بيانات لملكية بيانات بوابة الحساب وصلاحياتها.
- 192 فحصًا للبريد والتأكيد والتسجيل، و34 للمصادقة على WordPress/MariaDB.
- 46 فحصًا لحماية المصادقة دون قاعدة بيانات.

اجتاز فحص PHP الملفات الـ11 المعدّلة أو الجديدة، وفحص JavaScript والترجمة العامة وفحص سلامة الفرق. فحص Intelephense شمل 277 ملفًا وأبلغ عن صفر أخطاء مملوكة للمشروع، مع 102 تشخيص آخر.

التعثر السابق لمؤشر الكتابة لم يتكرر في تشغيل الحزمة العام النهائي بعد تنظيف جلسات الاختبار المكتملة. لم يُعدَّل ملف اختبار توقيت المؤشر أو مهلته أو منطق المحادثات. لا يُدّعى هنا اجتياز كل اختبارات المستودع خارج المجموعات المذكورة.

هذه مراجعة للكود والاختبارات المذكورة، وليست ضمانًا لجميع إضافات WordPress الخارجية أو إعدادات الاستضافة غير المختبرة.

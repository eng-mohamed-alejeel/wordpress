# استكشاف أخطاء الداشبورد الإداري

## تصنيف المشكلة أولًا

سجّل عنوان الصفحة، الدور، نطاق الفرع، اللغة، العرض التقريبي، وقت حدوث المشكلة، ورقم الطلب إن ظهر. لا تسجّل كلمة مرور أو رمز جلسة أو استعلام SQL أو بيانات عميل كاملة.

| العرض | الفحص الآمن | الإجراء التالي |
|---|---|---|
| الصفحة فارغة أو تعيد خطأ | فحص سجل PHP وفتح صفحة أخرى من نفس المجموعة | أوقف التغيير الأخير وافحص `php -l` للملفات المعدلة |
| الصفحة تظهر مرتين أو بتنسيق قديم | تحديث قسري ومسح cache الأصول ثم فحص تحميل CSS مرة واحدة | راجع مصدر الصفحة وعدم تحميل CSS القديم من قالب أو إضافة أخرى |
| لا تظهر وحدة | راجع الدور والصلاحية والنطاق، ثم جرّب رابط الصفحة مباشرة بالحساب نفسه | لا تمنح صلاحية إضافية قبل مراجعة مصفوفة الأدوار |
| يظهر سجل من فرع آخر | أوقف العملية ولا تعدّل السجل | راجع فحص النطاق في الخدمة وسجّل الحالة للتدقيق |
| زر الإرسال لا يعمل | افحص وجود nonce ورسالة التحقق واستجابة POST | لا تعطل nonce أو فحص الصلاحية كحل مؤقت |
| بطء متقطع | افتح صفحة التشخيص إن كانت مفعّلة وسجّل رقم الطلب والمدة فقط | قارن baseline قبل تعديل الاستعلام أو الجدول |
| رابط بريد يشير إلى localhost | راجع `home` و`siteurl` من إعدادات WordPress | اضبط النطاق العام وHTTPS قبل النشر |
| اختلاف العربية/الإنجليزية | جرّب اللغتين والوضع الفاتح/الداكن على نفس العرض | افحص النصوص والترجمة واتجاه RTL دون تغيير الصلاحيات |

## صفحة التشخيص

صفحة `admin.php?page=adc-diagnostics` قراءة ومراجعة للمؤشرات المختصرة. القياس اختياري ومعطّل افتراضيًا. لا تُظهر الصفحة SQL الخام أو رسائل الأخطاء الكاملة أو الأسرار. تفعيل القياس يتم من الصفحة بصلاحية مناسبة وnonce، أو من إعداد الخادم عند الحاجة التشغيلية.

عند مشاركة تقرير، شارك فقط: الصفحة، الطريقة، الحالة، المدة، رقم الطلب، وبصمة الخطأ. احذف أي قيمة قد تحتوي على بريد أو اسم عميل قبل إرسال التقرير.

## فحوص ما قبل التصعيد

```powershell
php -l path\to\changed-file.php
node --check path\to\changed-file.cjs
git diff --check
php tools\release-preflight.php --inspect
```

إذا كان الخلل مرتبطًا بتحديث، احتفظ بالحزمة وبصمتها وطبّق إجراء الرجوع الموثق في [UPGRADE-AND-ROLLBACK-2026-10-15-AR.md](UPGRADE-AND-ROLLBACK-2026-10-15-AR.md). لا تُسقط قاعدة بيانات الإنتاج كجزء من التشخيص.
